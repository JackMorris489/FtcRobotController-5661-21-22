## Welcome! 
This GItHub repository stands as an archieve of my team's *FIRST* Tech Challenge competition programs. This archieve is for the Freight Frenzy (2021-2022) competition season, which was my Senior year of Competition. 

## Navigation
This repository is a clone of whole *FIRST* Tech Challenge competition Android app & SDK. As such, a majority of this repository is code that *is NOT mine*. If you're looking specifically for what I created, then please navigate through the [TeamCode](https://github.com/JackMorris489/FtcRobotController-5661-21-22/tree/main/TeamCode) Folder to find [FtcRobotController-5661-21-22/TeamCode/src/main/java/org/firstinspires/ftc/teamcode](https://github.com/JackMorris489/FtcRobotController-5661-21-22/tree/main/TeamCode/src/main/java/org/firstinspires/ftc/teamcode).
I was responsible for all the programs within that folder, and while none of them are perfect, I remain quite proud of them and the work that was required to make it all work together.

## Downloading the Project
The following section has been copied from the original SDK's README, and may not be 100% accurate. There's little reason to download and run this locally, as without the required hardware this does nothing, but if you're curious feel free to follow these steps. 

If you are an Android Studio programmer, there are several ways to download this repo.  Note that if you use the Blocks or OnBot Java Tool to program your robot, then you do not need to download this repository.

* If you are a git user, you can clone the most current version of the repository:

<p>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;git clone https://github.com/FIRST-Tech-Challenge/FtcRobotController.git</p>

* Or, if you prefer, you can use the "Download Zip" button available through the main repository page.  Downloading the project as a .ZIP file will keep the size of the download manageable.

* You can also download the project folder (as a .zip or .tar.gz archive file) from the Downloads subsection of the [Releases](https://github.com/FIRST-Tech-Challenge/FtcRobotController/releases) page for this repository.

* The Releases page also contains prebuilt APKs.

Once you have downloaded and uncompressed (if needed) your folder, you can use Android Studio to import the folder  ("Import project (Eclipse ADT, Gradle, etc.)").
